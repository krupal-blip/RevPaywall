# FocusFlow RevenueCat Demo — Refactor & Integration Tasks

## Goal

Convert current “all screens inside MainActivity” demo into a cleaner modular structure for:

* RevenueCat Paywall UI demo
* Offerings demo
* Custom Attributes demo
* Placement-based monetization demo
* PM presentation clarity

Keep architecture simple and demo-friendly.

---

# PHASE 1 — Refactor MainActivity ✅ DONE

## Current Problem

Right now:

```text
MainActivity contains all screens/views
```

This makes:

* paywall placement logic messy
* RevenueCat demo hard to explain
* targeting flow unclear

---

## Task 1 — Separate Screens

Create separate Activities or Fragments.

Recommended:

| Screen                  | Type     |
| ----------------------- | -------- |
| SplashActivity          | Activity |
| OnboardingActivity      | Activity |
| HomeActivity            | Activity |
| PremiumFeaturesActivity | Activity |
| SettingsActivity        | Activity |

Keep it simple.
No need Navigation Component for demo.

---

## Task 2 — MainActivity Responsibility

Convert MainActivity into:

```text
App launcher / routing activity only
```

Example:

```kotlin
Check:
- first launch?
- logged in?
- onboarding complete?

Then redirect.
```
